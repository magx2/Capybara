= Module Tuple

== Types

[[type-Tuple]]
=== data Tuple

Native fixed-size ordered collection type backed by the runtime Tuple implementation.
Tuple literals use parentheses with at least two values: (1, "two").

Example:
```cfun
let pair = ("answer", 42)
pair[1] == 42
```

==== Functions

===== fun Tuple.get(idx: int): any

Returns the value at idx using the same literal-index rules as tuple[idx].
idx must be a non-negative integer literal within the statically known Tuple arity.
The compiler supplies the exact selected element type.
